WatchDesk — Astra Tools v1.1.0

Extract this ZIP. Open chrome://extensions, enable Developer mode, click Load unpacked and choose this folder. Pin the extension to open it.

Tabs, scripting, alarms, notifications and storage. Optional access to each monitored website.
Pro: 20 monitors; minimum 15-minute interval. Chrome must be running and the computer awake. Checks open a background tab. No cloud, email or SMS alerts.
Free: 2 local monitors. Activate a purchased licence inside the workspace.
