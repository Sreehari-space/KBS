FollowUp Desk — Astra Tools v1.1.0

Extract this ZIP. Open chrome://extensions, enable Developer mode, click Load unpacked and choose this folder. Pin the extension to open it.

Scripting, alarms, notifications and storage. Optional access limited to Gmail.
Pro: 200 saved conversations. Reminders require Chrome running. Activity is detected only on opened Gmail threads and needs manual review; no automatic reply verification or sending.
Free: 5 active reminders. Activate a purchased licence inside the workspace.
