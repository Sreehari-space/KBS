How matching and exports work

Choose one identifying column and one value column in each file. Keys are compared as text using your space and case settings. Duplicate or blank keys are flagged for review. Numeric mode compares decimal values exactly; it does not calculate taxes, reconcile payments or verify records.

CSV export includes every result in the selected filter and search, across all pages. Potential spreadsheet formulas are prefixed with an apostrophe. Excel files (.xlsx) must first be exported as UTF-8 CSV.
