DEVELOPER PREVIEW

Your tools, in your browser.

These are working developer preview builds. They are not yet published in the Chrome Web Store. You can try the web tools without installing anything.

Install on desktop Chrome

  1. Download your tool’s ZIP from its product page.
  2. Extract it into a permanent folder. Keep that folder after installation.
  3. Open chrome://extensions in your address bar.
  4. Turn on Developer mode, then choose Load unpacked.
  5. Select the extracted folder containing manifest.json.
  6. Pin the tool from Chrome’s Extensions menu.

In Microsoft Edge, use edge://extensions and the same steps. Mobile Chrome does not run these desktop extensions.

Open your tool

FileFit and ClaimPack open their workspace when clicked. ShareSafe captures the visible tab and opens the editor. DownloadRules opens its rules page; rules apply to new browser downloads after you save them.

RevisionDesk

Open a client message in desktop Chrome, select the relevant text, then click RevisionDesk or use the selection context menu. The hosted workspace opens. Choose a project, review the captured request and optionally redact and include the screenshot before saving. If capture transfer is blocked, open extension Options, export the pending capture and use Import capture in the workspace. Sign-in is required. Review links currently follow the private Site access restrictions.

The work collection

  • StepGuide: open the website to record, click its pinned icon, then choose Start recording in the workspace. Grant access to that website. Return to the workspace to stop, edit and redact before exporting. Screenshots require the same tab where you clicked the icon.
  • ReplyReady: create templates, fill personalisation fields and copy replies. Optionally enable a website, then type ;shortcut followed by Space in an ordinary text input or textarea.
  • WatchDesk: open a page, choose Pick an area, select the text, then save and enable the monitor. Two matching checks confirm changes. Chrome must stay running.
  • FollowUp Desk: optionally enable Gmail integration, open a conversation and choose Track follow-up. Set a reminder. Review new activity and mark replies yourself. No email is sent automatically.

Activate a purchase

Open the tool, expand “Have a licence?”, paste your complete licence code, and select Activate licence. Each code is specific to one product and major version.

Permissions, kept small

  • FileFit and ClaimPack: storage for the licence and local free-use count.
  • ShareSafe: storage and active-tab access when you click its icon.
  • DownloadRules: downloads and storage for your sorting rules.

The work tools use storage and optional site access. StepGuide also uses active-tab capture and scripting; ReplyReady uses scripting; WatchDesk uses scripting, tabs, alarms and notifications; FollowUp Desk uses scripting, alarms, notifications and optional Gmail access. Website tab selectors require tab-list access. These four tools keep their content locally. RevisionDesk stores project details and selected evidence in hosted storage; its capture permissions apply only when you use it.

Update or remove

Replace the extracted files with a newer compatible build, then click Reload on the extensions page. To uninstall, choose Remove. Export your DownloadRules settings first if you want to retain them.
